# NexaAffiliates — Testing Documentation

## 1. Overview

Testing is used to verify that the NexaAffiliates portfolio simulation works correctly across its major modules.

The project is a static front-end application built with HTML, CSS and Vanilla JavaScript.

Testing focuses on:

- Functionality
- Navigation
- Data rendering
- Filtering
- Responsive behavior
- Asset paths
- Browser compatibility
- GitHub Pages compatibility

All testing data is fictional.

---

## 2. Testing Objectives

The main objectives are:

- Verify that all pages load correctly
- Verify that navigation works
- Verify that JavaScript modules initialize correctly
- Verify that fictional data renders correctly
- Verify that filters work
- Verify that search works
- Verify that reset buttons work
- Verify that demo actions provide appropriate feedback
- Verify responsive layouts
- Verify GitHub Pages relative paths
