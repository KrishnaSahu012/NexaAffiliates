# NexaAffiliates — Affiliate Account Manager Portfolio

## 1. Project Overview

NexaAffiliates is a fictional portfolio simulation designed to demonstrate the workflow and responsibilities of a Junior Affiliate Account Manager in a US-focused CPA/CPL performance marketing environment.

The project presents a browser-based account management dashboard where fictional offers, affiliates, advertisers, campaigns, performance data, compliance reviews, communications, reports and case studies can be reviewed in one place.

> **Important:** NexaAffiliates is a portfolio simulation. All organizations, affiliates, advertisers, campaigns, metrics, revenue figures and activities shown in the project are fictional and created for demonstration purposes.

---

## 2. Project Objective

The primary objective of this project is to demonstrate practical understanding of affiliate account management workflows.

The simulation focuses on:

- Affiliate relationship management
- Advertiser coordination
- Offer management
- Campaign management
- Performance monitoring
- CPA/CPL marketing concepts
- Traffic source monitoring
- Compliance review workflows
- Account communication
- Reporting
- Performance optimization
- Case-study analysis

### Performance

The Performance module demonstrates basic affiliate marketing analytics.

Example metrics include:

- Clicks
- Conversions
- Conversion rate
- Revenue
- EPC
- Traffic source performance

#### Conversion Rate

Conversion rate is calculated as:

`Conversions ÷ Clicks × 100`

#### EPC

EPC is represented as:

`Revenue ÷ Clicks`

All performance values in the simulation are fictional.
