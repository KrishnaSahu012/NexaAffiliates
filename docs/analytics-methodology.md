# NexaAffiliates — Analytics Methodology

## 1. Overview

Analytics helps an Affiliate Account Manager understand campaign activity and identify areas that may require attention.

The NexaAffiliates simulation demonstrates a simple analytics methodology using fictional campaign performance data.

All metrics, revenue values and campaign results in this document are fictional.

---

## 2. Analytics Objectives

The main objectives are:

- Monitor campaign performance
- Understand traffic activity
- Measure conversions
- Calculate conversion rates
- Calculate EPC
- Compare traffic sources
- Identify optimization opportunities
- Support reporting
- Communicate performance clearly

---

## 3. Core Performance Metrics

The NexaAffiliates analytics module uses the following metrics:

| Metric | Meaning |
|---|---|
| Clicks | Number of recorded campaign clicks |
| Conversions | Number of recorded conversions |
| Conversion Rate | Percentage of clicks that converted |
| Revenue | Fictional revenue associated with conversions |
| EPC | Fictional earnings per click |
